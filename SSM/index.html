СКИН
РЕЖИМ (ПОЛЕ MODE)
Режим влияет на поле «mode» и на базовые цвета Classic. Переключение оставляет ваши кастомные цвета нетронутыми, а нетронутые базовые — перекрашивает.
ПРЕСЕТЫ
ЦВЕТА
Форматы: #hex, rgb(), rgba(), hsl(), hsla(). Пустое поле — вернуть значение по умолчанию. Чип рядом с «текстовыми» переменными — контраст по WCAG (норма 4.5:1).

ТЕКСТ
ЭФФЕКТЫ
Тень/свечение пишутся в формате box-shadow: «смещение смешение размытие цвет», например 0 4px 16px rgba(0,0,0,.2). Blur размывает панели изнутри (backdrop-filter).

ЭКСПОРТ
Ссылка вида …/#skin=… открывает Skyle сразу с этим скином. SSM тоже понимает такие ссылки — откройте её в браузере, чтобы отредактировать скин здесь.
ИМПОРТ
Ссылка с #skin=… импортируется автоматически при открытии страницы. Неизвестные переменные игнорируются, некорректные значения отбрасываются с предупреждением.
